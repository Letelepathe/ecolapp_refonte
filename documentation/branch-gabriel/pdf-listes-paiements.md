# PDF des listes de paiements

- L'aperçu d'impression affiche le logo et le nom de l'école active.
- Les critères de classe et de période apparaissent dans le document.
- Le nombre de paiements et les totaux sont affichés.
- Les montants sont totalisés séparément par devise afin d'éviter une somme
  financière incorrecte entre devises différentes.
- Le même aperçu peut être imprimé ou téléchargé en PDF.
- Les longues listes sont réparties sur plusieurs pages PDF en orientation
  paysage.
- Le composant commun couvre les paiements en ordre et avec dette des trois
  cycles.
