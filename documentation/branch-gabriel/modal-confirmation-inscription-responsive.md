# Modal de confirmation d'inscription

La modal partagée par le secondaire, le primaire et la maternelle a été rendue utilisable sur les écrans courts et mobiles.

- L'en-tête et les boutons d'action restent visibles.
- Le contenu central possède son propre défilement vertical.
- Les boutons se réorganisent sur un écran étroit.
- Un bouton de fermeture accessible a été ajouté.
- Une erreur claire apparaît si les types d'élèves ne peuvent pas être chargés ou si aucun type actif n'existe.

La correction est centralisée dans `ConfirmationInscriptionModal` et son style ciblé ; elle ne modifie pas les autres modales de l'application.

Cette version est destinée au test local et n'est pas déployée automatiquement.
